# Portfolio description

**Short (one line)**

GreenField Seeds — a fictional seed shop landing page built with semantic HTML5 and hand-written CSS.

**Medium (card/blurb)**

GreenField Seeds is a single-page demo storefront for a fictional agricultural seed shop. It explores paddy, mustard, and black sesame through a calm forest-green, cream, and gold palette. Built with semantic HTML5 and plain CSS — no frameworks, no JavaScript — with a focus on responsive layout, accessible markup, and honest placeholder content.

**Long (case study intro)**

GreenField Seeds is a portfolio exercise in restraint: how do you make a small business page feel premium without inventing claims to fill space? The result is a responsive, single-page site for a fictional seed shop stocking three crops — paddy, mustard, and black sesame. Everything is hand-written HTML5 and CSS: a sticky navigation with a skip link, a hero with fluid `clamp()` typography, a three-card product grid on CSS Grid, and layouts tuned for 360px through desktop. The design uses a forest-green and cream base with muted gold accents, Lora for headings and Raleway for body copy. Accessibility is built in rather than bolted on — semantic landmarks, one clear `h1`, descriptive alt text, visible focus rings, and reduced-motion support. The content deliberately avoids fake prices, yields, certifications, or testimonials; the brand, inbox, and imagery are labelled as placeholders so the demo can be shown honestly.
